# Moodcaster 🎭

A Farcaster Mini App for creating and voting on mood-based polls. Built with Next.js, TypeScript, and MongoDB.

## Features

- **Create Polls**: Make custom polls with multiple options
- **Vote & Engage**: Vote on polls and see real-time results  
- **User Profiles**: View profiles with poll statistics and voting history
- **Farcaster Integration**: Seamless authentication using Farcaster Quick Auth
- **Neo-Brutalist Design**: Bold, modern UI with strong visual elements

## Tech Stack

- Next.js 15 with React 19
- TypeScript
- MongoDB with Mongoose
- Farcaster Quick Auth
- Neynar API integration
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Environment Variables

Create a `.env.local` file with:
```
MONGODB_URI=your_mongodb_connection_string
NEYNAR_API_KEY=your_neynar_api_key
NEXT_PUBLIC_HOST=http://localhost:3000
```
